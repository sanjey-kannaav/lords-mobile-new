# Cross-Agent Change Requests

Only `01-architect` (and `02-database` for schema specifics) may edit the
`docs/*.md` contract files directly. Every other agent that needs a change to
a shared contract logs it here instead of editing directly, so changes are
visible to everyone working in parallel.

Format:

```
## [YYYY-MM-DD] <requesting-agent> → <owning-agent>
**File:** docs/xxx.md
**Request:** what needs to change and why
**Status:** open | accepted | rejected
```
